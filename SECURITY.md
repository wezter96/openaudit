# Security policy

openaudit reads untrusted repositories, artifacts and websites, so we treat bugs that let a scanned target affect the machine running openaudit as security issues. That includes path traversal, command execution, credential leakage and SSRF in the hosted API.

Report vulnerabilities privately through GitHub Security Advisories ("Report a vulnerability" on the repository's Security tab). Do not open a public issue. We aim to acknowledge reports within 3 working days.

Only audit systems you own or are authorised to test.
